# VizCoach docs

These pages follow four kinds of documentation: a tutorial for a first run, how-to guides for one task, reference for routes and data, and an explanation of why the app is split this way.

| Page | Kind | Read it when |
| --- | --- | --- |
| [tutorial-first-class.md](tutorial-first-class.md) | Tutorial | You want the app running locally and a teacher account signed in |
| [howto-import-students.md](howto-import-students.md) | How-to | You are adding a class from a CSV |
| [howto-deploy-netlify-jetstream.md](howto-deploy-netlify-jetstream.md) | How-to | You are publishing the public demo |
| [reference-routes.md](reference-routes.md) | Reference | You need a path and which role can open it |
| [reference-collections.md](reference-collections.md) | Reference | You need a collection, field, or API rule |
| [reference-env-and-scripts.md](reference-env-and-scripts.md) | Reference | You need an env var or a shell script |
| [explanation-architecture.md](explanation-architecture.md) | Explanation | You want the reason for the roles, CSV hook, and two hosts |
